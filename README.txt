এ প্লাস ম্যাচিং সেন্টার — বাংলা ওয়েবসাইট
========================================

ফাইল:
- index.html — মূল ওয়েবসাইট
- logo.png — লোগো
- banner.png — কভার/হিরো ব্যানার

লাইভ করার সহজ উপায়:
1. GitHub-এ নতুন একটি repository তৈরি করুন।
2. এই তিনটি ফাইল upload করুন।
3. Settings → Pages → Deploy from a branch → main → /(root) → Save।
4. কিছু সময় পর GitHub Pages-এর "Visit site" থেকে ওয়েবসাইট খুলুন।

পরে index.html-এ ফোন নম্বর, WhatsApp, Facebook Page, ঠিকানা এবং আসল পণ্যের ছবি যোগ করা যাবে।
